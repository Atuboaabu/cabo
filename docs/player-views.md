# CABO — Player Views & Information Visibility

> 版本：Draft 0.1（Phase 3 已审核）  
> 状态：信息权限与业务发布边界已确认；具体消息字段及传输机制留待 Phase 4  
> Source of Truth：`docs/game-rules.md`；上游约束：`docs/domain-model.md`、`docs/state-machine.md`、`AGENTS.md`

## 1. 目的与原则

本文整理已确认的 Phase 3 PV-1 至 PV-16 决策，规定 CABO 各接收者**可以知道什么、何时能知道、何时不再有权获取**，不设计数据库、后端代码、API/WebSocket 具体消息格式、持久化或基础设施。

- **Contract First + Server Authoritative**：服务器保存唯一完整真实牌局，按可信身份、当前状态和授权形成对外结果。
- **Least Disclosure**：背面牌数字无权知道时，负载里不应存在该字段；禁止发送完整秘密状态再靠 UI 隐藏。
- **Current State ≠ Historical Log**：当前公开事实必须可见，但不提供无限回溯的弃牌历史、公开动作日志或秘密记牌辅助。
- **曾经知道 ≠ 仍可重新读取**：玩家可以记忆、推理、截图，但服务器不会永久提供已过期的隐藏数字。
- **Decision Frozen ≠ Effects Committed**：多牌 Replace 决策冻结不代表公开牌列变化正式成立。
- **信息契约分离 ≠ 网络通道强制分离**：本阶段区分信息内容与授权，不指定接口或传输拓扑。

## 2. 对外信息出口

| 类别 | 业务内容 | 合法接收者 |
| --- | --- | --- |
| Authoritative Domain State | 所有真实牌值、稳定内部 Card 身份、当前授权及必要历史 | 仅服务器，不是通用客户端负载 |
| Ordinary Player View | 当前可公开的牌局、Room、Game、Round、Turn 进度 | 依可信身份为合法玩家构建 |
| Public Event | 已正式成立、允许公开的动作事实；负载本身无秘密字段 | 当前有权接收的玩家 |
| Acting Player Decision Context | 当前合法操作、候选目标、剩余选择及已确认不可撤销的任务事实 | 仅当前行动者 |
| Current Action Private Result | 正在处理的 DrawPile 抽牌真实数字 | 仅当前行动者，按当前处理阶段授权 |
| Temporary Reveal Result | InitialReveal、Peek 或 Spy 对特定隐藏牌的临时秘密结果 | 仅当前合法查看者 |
| Latest Completed Round Result | 最新正式完成轮次的最终完整牌列与结构化得分原因 | 该 Game 的合法参与者 |
| Historical Round Score Summary | 同 Game 更早已完成轮次的必要正式得分 | 该 Game 的合法参与者 |
| Game Progress / Result | 累计、重置、终局状态与 Winner | 该 Game 的合法参与者 |

身份不能由用户提供的 Room ID、Game ID 或玩家姓名自证；历史参与者权限不能仅因当前不再属于 Room 就被错误视为该局不存在。跨 Game 历史查询的入口/范围仍待定；不自动授予观战者任何玩家权限。

## 3. Ordinary Player View：当前状态而非完整历史

### 3.1 允许提供的当前信息

- Room 当前状态、成员、房主和公开 Lobby Ready；Game 当前状态、固定参与者、座次、当前 Round 编号与公共阶段。
- 当前合法行动者、90 秒 Turn 的**整体权威截止进度**；无活动 Turn 时不能伪造一个。
- CABO 呼叫者、FinalTurns 对当前合法调度仍有影响的公开事实。
- 每人牌列**长度、位置顺序、正反面状态**；正面 Card 的真实数字；背面 Card 数字不在普通视图中出现。
- DrawPile 剩余数量；DiscardPile **当前顶部**数字（若存在）和必要数量。
- 已正式应用的 Game Total、适用的 100→50、Game 终局；属于合法范围的正式结算视图。
- Settling 期间公开进度但**不揭示完整隐藏最终手牌**；Round Aborted 不因结算视图而泄漏隐藏牌。

### 3.2 当前公开事实与不可回溯历史

- 在当前牌列内仍正面朝上的 Card，其数字持续公开，直至该 Card 依法离开或状态改变。
- 弃牌堆顶部被取走后，新顶部自然公开；曾经公开、现在被盖住的旧顶部不作为普通历史供查询。
- 只提供弃牌堆当前顶部与必要数量，不提供整个堆的历史数字序列。
- 已过去的 Peek/Spy 结果、旧公开动作、旧牌列变化不构成普通 Player View 的永久回溯日志。
- 玩家合法观察到的公开位置移动可以自行记忆和推理，但视图不提供稳定公开 Card ID 或自动追踪标签。
- 服务器保留必要 Turn 摘要及业务历史，不代表向玩家开放完整回放。
- 断线重连获取当前权威安全视图，不要求重放断线期间所有公共事件。

## 4. Public Event：只描述已成立的公开动作

Public Event 是**独立的对外安全契约**，本身不得包含需要按接收者删除的背面真实值、当前隐藏抽牌数字或内部稳定 Card ID。同一动作可产生公共事件及独立的授权私人结果。

| 正式业务事实 | 公开事件可说明 | 禁止或延迟披露 |
| --- | --- | --- |
| DrawPile 取走一张 | 谁取牌、公开牌堆数量变化 | 私人抽牌值 |
| DiscardPile 取顶部 | 谁取走哪张已公开牌、当前新顶部 | 未公开隐藏值 |
| 正式弃牌 | 弃牌数字、新顶部 | 尚未执行的技能意图 |
| Peek 目标正式确认 | 使用者、自己被查看的**当时位置** | 背面数字 |
| Spy 目标正式确认 | 使用者、目标玩家、**当时位置** | 背面数字 |
| Swap 正式执行 | 自己/他人双方玩家及**交换时两端位置** | 背面值、内部 ID、尚未确认的任一端 |
| 单牌 Replace 生效 | 公开旧牌及正式公开结果 | 背面新抽牌值 |
| 多牌 Replace 全部 Effects Committed | 正式成功/失败、已公开旧牌、完整牌列和弃牌堆变化 | Decision Frozen 但尚未放置完成的判定 |
| CABO 正式呼叫 | 呼叫者与进入 FinalTurns 的公开事实 | 虚构的后续 CABO |
| Turn、Game 正式终结 | 合法当前公开结果 | 未完成 Round 的隐藏终局牌 |

**PV-16 未完成行动边界**：从抽牌堆正式取走牌本身已发生，可公开「抽牌」；玩家尚未选择是否弃牌/Replace，不额外公开正在考虑的意图。Replace 已冻结但仍 AwaitingPlacement，不向其他玩家公开匹配结果、已选旧牌翻面或未完成的方向。Peek/Spy **目标一经正式确认**就按照 PV-6 公布目标位置，即使 15 秒查看尚未结束；目标选择草稿不公开。Swap 两端完整确认且正式交换后才公布双方位置；不能公布单端草稿。

多牌 Replace 的完整公开牌列变化只在全部所需保留位置/新牌方向/惩罚牌方向确定并正式生效后一次产生；未提交时 Game 被强制 Aborted，不能披露曾冻结的成功/失败及旧牌数字。最后**主抽牌**三张以上失败并触发 House Rule 特例没有待放置阶段，正式效果成立后即按合法公开规则通知；惩罚牌抽空牌堆不能错误套用该特例。超时兜底完成的正式动作正常公开，但不需要曝光玩家是否实际读过秘密结果。

Public Event 不提供可无限回溯的完整操作日志。已完成但错过的即时通知不必一一补发；**当前仍有效的事实**（CABO 呼叫者、FinalTurns、公开牌、弃牌顶部等）必须通过普通视图重建。旧 Playing 消息不得覆盖新的 Completed / Aborted 权威状态；具体版本识别留待 Phase 4。

## 5. Acting Player Decision Context

### 5.1 仅当前行动者的合法决策上下文

服务器依据 Turn 当前权威状态、抽牌来源、已提交步骤、剩余时间及牌列现状，提供**当前合法操作和目标位置集合**，以及所剩任务与不可修改的已确认选择。它是操作辅助/授权信息，不是抽牌秘密数字或 Peek/Spy 秘密数字的来源。

普通玩家不直接接收其他人内部 Turn 状态名称，例如 AwaitingCardDecision、AwaitingPlacement、AwaitingAbilityTarget、AwaitingRevealConfirmation。公开 Turn 进度只显示行动者、整体截止、已经成立的合法公开动作与正式结果。

### 5.2 目标引用与重新验证（PV-14、PV-15）

- 对外目标使用**玩家身份 + 当前牌列位置**，而不是稳定内部 Card ID。
- 提交时服务端必须重新验证：可信行动者、合法活动 Turn、当前决策上下文、仍适用的牌列布局、合法目标及该决策尚未结束。
- 位置的数字仍在合法范围内，不代表与旧 Context 中是同一张 Card。旧位置**不得自动映射**到插入/移除后的另一张牌。
- 重复请求不得被误解释为新阶段的选择；旧 Swap、Peek/Spy 或 Replace 决策不能被重放。
- Peek/Spy 目标正式确认后绑定服务端该次确定的**具体 Card**，不能以后用旧位置数字动态寻找新 Card。
- 服务端提供候选是展示便利而非最终合法性保证；命令正式受理时必须重新校验。

### 5.3 不同决策的合法候选

| 决策/来源 | 合法操作或目标 |
| --- | --- |
| 正常 Turn 开始 | 合法牌堆抽牌，或仅在正常 Playing 且 Turn 起点呼叫 CABO |
| DrawPile 牌待处理 | 可弃牌（符合牌值与来源条件时选择相应能力）或合法 Replace；**牌值另走私人结果** |
| DiscardPile 牌待处理 | 必须 Replace，不可直接弃掉，不可使用 7–12 对应能力 |
| Peek | 自己当前背面牌位置 |
| Spy | 其他玩家当前背面牌位置 |
| Swap | 自己一张与另一玩家一张，正面和背面均可 |
| Replace 旧目标 | 自己合法旧牌位置，允许多选不同位置；不按隐藏值限制为同值组合 |
| 已冻结 Replace 成功 | 仅从已选旧牌位置中选择新牌保留处 |
| 已冻结 Replace 普通失败 | 先选择新牌左/右端，再按需要独立选择惩罚牌左/右端 |

候选不能按玩家无权获知的隐藏值**筛选、排序、提示「必成功」**，否则泄漏未知牌值并破坏多牌失败的合法风险。技能选项可依据行动者当前有权通过私人抽牌结果知道的数字合法开放，但不得将该数字复制进公共视图或公共事件。

### 5.4 冻结、放置与失效

正式提交多牌 Replace 后，选中旧牌与匹配结果冻结；未正式提交的客户端勾选草稿不冻结。已确认的新牌方向不能被惩罚牌方向请求覆盖。所有必要选择完成才一次性提交公开牌列。Game Abort 时未提交完整结果的牌列效果不生效。

超时遵循 Phase 2：DrawPile 待决定默认弃掉且不使用能力；DiscardPile 待决定默认替换最左合法旧牌；Replace 成功保留位置默认已选位置最左；失败未决新牌/惩罚牌方向分别默认左端且保留已确认方向；技能目标未确认则跳过；Peek/Spy 查看到期撤销授权。超时后旧 Decision Context 失效，不因重连复活。

## 6. 两种独立私人结果

### 6.1 Current Action Private Result（PV-2）

- 只针对本次从 **DrawPile** 正常取得、尚在**可决定如何处理**阶段的牌；仅当前行动者可获知真实数字。
- **不是 Temporary Reveal**，不使用 Peek/Spy 的 15 秒上限。
- 有效期依当前抽牌处理决策：通常 AwaitingCardDecision 时有效；决定弃牌/能力或正式冻结 Replace 后即结束，而不必等待整个 Turn 完成。
- 重连且仍处于同一有效处理阶段时，可恢复**同一张已取得的牌**，不能重抽或重新给予 90 秒。
- 权限失效后不得继续通过旧私人结果查询；牌正式弃到 DiscardPile 后数字由公开牌堆事实提供。
- 抽到 DrawPile 的最后一张不使当前私有处理权限提前失效，须允许当前合法动作完成后 Round 才 Settling。

### 6.2 Temporary Reveal Result（PV-1）

**InitialReveal**：每位玩家每轮最多看两张**不同**的初始牌，45 秒为该玩家**总机会**。提前结束会放弃剩余机会，尚有机会时应二次确认；确认期间不暂停时限。所有玩家的初始查看终结后才授予首个 Turn。

**Peek / Spy**：Peek 只能查看自己一张背面牌，Spy 只能查看其他玩家一张背面牌；合法目标确认后固定服务端具体 Card。授权最长 15 秒，并在原 Turn 90 秒截止之前结束。目标确认后不得重选；若结果尚未实际展示，提前关闭需要防误触确认；已展示可直接关闭。确认提示不暂停倒计时。

- 只向特定合法查看者提供目标数字；Public Event 仅公开合法的使用者和确认时目标位置（Spy 另公开目标玩家）。
- 初始查看的个人精确剩余时间与 Peek/Spy 的精确授权时间只提供给**本人**，不向其他玩家提供。
- 查看授权结束、超时、所属 Turn/Round/Game 有效终结或强制中止时失效。断线不暂停/重置；原授权仍有效才恢复**同一目标及剩余时间**。
- 主动关闭、到期和中止的竞合只能产生一次终结。旧目标不可被重新选取，旧授权不能重开；也不提供永久 PlayerKnowledge。
- 玩家已看到的数字可凭记忆使用，但服务端无法消除既有记忆；这不构成新的秘密读取权限。
- **安全待决**：截止前正式受理读取、但值在截止后实际送达时的披露裁决。截止后新请求不能获秘密值；具体竞合规则在 Phase 4 明确。

## 7. Card 的公开性、位置及可追踪性

- 初始牌及 DrawPile 替换入列牌背面；DiscardPile 替换入列牌正面。正面牌当前值持续公开。
- Peek/Spy 只揭示给授权者，不改变 Card 正反面；普通 Player View 即使对查看者本人仍显示背面。
- Swap 交换自己的牌与另一玩家的牌，两张具体 Card 均保持原正反面。双方位置按**动作发生时**公开；原正面数字移动到新位置仍公开，背面数字仍保密。
- 多牌成功时公开旧牌入弃牌堆，保持未选旧牌的相对顺序；失败时旧牌原位翻开、新牌与必要惩罚牌按规则插入。所有完整结果在 Effects Committed 后才进入公共视图。
- 玩家可能根据公开 Peek/Spy 位置、Swap、左端插入等变化自行跟踪已知牌，这是合法推理；不应额外提供跨动作的公开稳定 Card ID、持久已知值标记或自动追踪服务。
- 位置变化后，旧 Context 的同编号目标即使仍存在，也不能自动代表旧 Card。

## 8. 公共进度和私人倒计时（PV-12、PV-13、PV-16）

| 进度信息 | 可见性 |
| --- | --- |
| 当前行动者、Turn 90 秒整体截止、Room/Game/Round 当前公共阶段 | 公开 |
| InitialReveal 每人的 45 秒精确剩余 | 仅本人 |
| Peek/Spy 最多 15 秒精确剩余 | 仅当前授权查看者 |
| 其他玩家完整内部 Turn 状态名 | 不提供 |
| AwaitingPlacement、未确认目标、未确认方向、已冻结但未生效的匹配结果 | 仅在行动者必要 Decision Context 提供 |
| Peek/Spy 已确认目标位置 | 按公共事件决策公开，秘密数字独立保密 |
| 查看者是否已实际读过结果 | 不公开 |

初始查看中**每名玩家完成/等待状态是否逐人公开**尚未单独决定；不要从「精确时间私人」推断其已批准公开。可以公开 Round 仍在等待与整体阶段转移。

所有合法时限由服务器判断；客户端计时仅供显示。二次确认不暂停时钟。其他人根据公开 90 秒总期限推测剩余 Peek/Spy 最长时长属于合法推理，但不能据此获取秘密授权。

## 9. Latest Completed Round Result 与 Game Progress

### 9.1 对外结算一致性（PV-11）

1. Round `Settling` 期间不提前公开完整隐藏最终手牌。
2. Round **正式 Completed** 形成真实最终手牌和 Round Score。
3. Game 对本轮 Round Score **恰好应用一次**；全部玩家完成加分、每人每局至多一次「首次恰好 100→50」重置。
4. Game 对**全部最终累计**完成 `>100` 终局判断及 Winner 选择。
5. **以上完成后**才开放相互一致的 Latest Completed Round Result 与 Game Progress / Result；不能展示新 Round Score 搭配旧累计。
6. 若 Game 尚未正常结束，按照 Phase 2 的 SM-G3，处理下一 Round 正式启动前已有效到达的 Kick/Disband；如果因此 Aborted，就不启动下一 Round。对外当前 Game 状态应反映最终有效结果，不得让旧 Playing 通知覆盖 Aborted。
7. 若无中止，自动开始下一 Round InitialReveal；该轮新牌保持隐藏，上一轮最近完整结算仍可查询。

业务开放一致性**不规定**多类通知的严格网络到达顺序，也不要求公开结算事件必须先于房主管理操作送达。命令/结果的新旧识别留待 Phase 4。

### 9.2 结构化 Round 计分明细（PV-10）

仅最近一个 Completed Round 可获得完整最终牌列及正式分数依据：

- 每位参与者最终完整牌列的**数字及顺序**。
- 每人 **Actual Hand Sum**（真实手牌数字总和）。
- CABO 呼叫者及成功/失败；呼叫者最低或**并列最低**实际总和算成功、得 0，否则通常总和 +10。
- 最后**主抽牌**至少三张旧牌替换失败的适用额外 +10；该分值不参与 CABO 是否最低的判断。
- Kamikaze 精确 `[12,12,13,13]`：持有者 0，其他人各 50，**覆盖**常规 CABO 与额外 +10，不是普通加减项。
- 每名玩家最终正式 **Round Score**，独立于 Actual Hand Sum。

不包含本轮全部历史动作、过去每次牌列变化、全部 Peek/Spy 读取记录或内部 Card ID。

### 9.3 独立的 Game Progress / Result

- 每名玩家最新 **Game Total**；每人本局重置资格是否已用及本轮适用的 100→50 结果。
- Game Playing / Completed / Aborted；只有 Completed 有 Winner。
- **最终有人累计 >100** 才结束；Winner 从**全部玩家**选最终 Game Total 最低者，并列比最后一个 Completed Round 的正式 Round Score，仍并列共同获胜。
- Game Total 不必等于 Round Score 的算术总和，因为存在 100→50；重置不改写任何 Round Score。
- Game 下一 Round 起始玩家由上一 Round 最终 Round Score 最低者决定，平分从上一 Round 起始玩家**本人开始**顺时针选第一个；不由前端用累计重新推算。

### 9.4 已完成历史可查询范围（PV-9）

- 当前 Game **最近一个 Completed Round** 的最终牌列及结构化计分明细可查询。
- 同 Game 更早 Completed Round **只提供必要的正式 Round Score 摘要**，不再提供旧完整最终牌列。
- 新 Round 自动开始后，上一轮完整结算仍可查询；断线玩家不会因为错过瞬时通知而失去最新结算。
- Game 正常 Completed 后，最后一轮完整结算、Game 最终累计与 Winner 仍可见。
- Game 后续 Aborted 不会回写历史 Completed Round；未完成的活动 Round Aborted 无正式得分，也**不自动揭示所有隐藏牌**。
- Room 关闭不改写历史。Room 又开始另一 Game 后，对旧 Game 结果的跨局查询入口及范围**未决**，不在本文件中默认开放无限历史。

## 10. 断线、重复通知与安全失效

- 断线不改变成员、房主、Game 参与者或 Turn/查看时限；重连通过服务器可信身份恢复**当前**合法信息，不通过客户端缓存重构真相。
- 当前玩家的 Decision Context、Current Action Private Result、Temporary Reveal 仅在**原阶段或原授权仍然有效**时恢复，不能重抽、重选目标、重新获得 45/15/90 秒。
- 断线期间错过公共事件无需完整重播；仍在当前状态中的公开牌、CABO 呼叫者、FinalTurns、弃牌顶部及 Game 累计必须正确恢复。
- 已正式执行 Swap、已生效 Replace、已结算 Round 的重复结果不能再次执行、再次加分或创建下一 Round。
- 旧 Playing 状态不能覆盖当前 Completed/Aborted；已完成 Turn 的旧 Decision Context 必须不可用。
- 公开错误消息、日志、调试内容、客户端缓存、前端 Mock 与身份切换都不能成为秘密牌值泄漏的旁路；具体实现控制在后续契约及代码阶段讨论。
