# CABO — Domain Model

> 版本：Draft 0.2（Phase 1 审核稿）  
> 规则依据：`docs/game-rules.md`  
> 协作约束：`AGENTS.md`  
> 状态：Phase 1 核心领域语义已确认；待决事项保留至后续阶段

## 1. 目的与边界

本文记录 CABO 在线多人游戏的领域概念、职责、生命周期、业务不变量与已确认的在线交互策略。

采用 **Contract First + Server Authoritative**。玩法规则以 `docs/game-rules.md` 为 Source of Truth；本文不得擅自改变该规则中的牌面行为、计分或胜负判定。

本文**不规定** ORM、数据库表与字段、Aggregate Root 的最终划分、HTTP/WebSocket 协议、事务或锁、定时器与任务调度、Redis、部署或前端组件。领域职责归属不等于调用链，更不等于持久化边界。

新增的限时与自动兜底政策属于**本项目线上策略**，不是 CABO 2019 原版规则；后续需同步修订规则文档中目前标记为待定的在线策略章节。

## 2. 概念总览

- **Room**：成员组织、房主权限、准备及开局。
- **Game**：一局固定参与者的多 Round 游戏，管理累计、结束条件、获胜者及下一轮决策。
- **Round**：独立洗牌发牌的一轮牌局，管理牌堆、持牌、初始查看、行动调度与轮次计分。
- **Turn**：某位玩家的一次行动机会，具有独立身份及生命周期。
- **Card**：一张具体牌，在所属 Round 内有稳定的内部身份。
- **CardSlot**：牌在玩家有序牌列中的当前**位置关系**，不具备独立领域身份。
- **Temporary Reveal**：对特定隐藏牌的合法、限时查看权限；不预设独立 Entity。
- **PlayerKnowledge**：MVP **不建立**永久记牌/观察知识实体，不提供自动记忆辅助。

这些概念上的层次不代表必须分别拥有独立 Aggregate 或数据库表。

## 3. Room

### 3.1 成员与加入

- Room 最多 **4** 名成员；开始 Game 时必须有 **2–4** 人。
- Game 进行期间禁止新成员加入，普通成员不能正式退出。
- Game 结束后 Room 可以继续使用；若未关闭且成员少于 4 人，可接纳新成员。
- 断线不等于退出 Room，也不自动删除 Game 参与者身份。
- MVP 不支持观战。

### 3.2 Ready 与 Start

- 非房主成员各自 Ready；房主不需要 Ready，主动执行 **Start** 即表示同意。
- Start 需要 Room 处于可开局状态、人数合法、所有非房主 Ready，并且不存在正在进行的 Game。
- Start 创建**新的** Game，冻结参与者集合及顺时针座次。
- Ready 是对**下一局**的准备意愿，不跨 Game 保留。
- Game 正常结束或因剔除玩家异常终止后，Room 回到 Lobby，剩余非房主成员的 Ready 重置。

### 3.3 房主的管理操作

- **Kick Player**：Game 正在进行时，房主可以剔除目标玩家；当前 Game 强制 Aborted，记录被剔除者与操作者；移除该 Room 成员，Room 回 Lobby，重置 Ready。后续允许加入新成员或人数合法时重新开始新的 Game。
- **Disband Room**：房主可以解散 Room；如果有活动 Game，先使其强制 Aborted，Room 随后 Closed，不再接纳成员或开局。
- 房主管理行为可终止 Game，但不能直接篡改 Game 牌值、合法行动结果或计分。
- Room 概念生命周期包括 Lobby、Playing、Closed；这里不是最终状态枚举。

## 4. Game

### 4.1 职责

Game 负责固定参与者及座次、跨 Round 累计得分、每位玩家本局一次性的 100→50 重置资格、应用正式 Round Score、判断 Game End、确定获胜者，以及自动开始下一 Round 的业务决策。

Game 不负责单次 Peek、Spy、Swap 或 Replace 的操作细节。参与者集合与座次在 Start 后固定；断线或随后剔除成员不改写原 Game 的历史参与者。

### 4.2 结束结果与历史

- **Completed**：按 CABO 规则正常结束，保存有效 Round、累计分数和最终获胜者（可多人共同获胜）。
- **Aborted**：房主管理行为提前终止；保留已完成 Round、累计及必要历史，**没有获胜者**；记录原因及相关操作者/对象。
- 当前已确认的中止原因是 `PLAYER_KICKED` 与 `ROOM_DISBANDED`（示意领域名称，非协议字段规定）。
- 终局 Game 不再恢复为 Playing；Room 再开局创建另一个 Game。

### 4.3 跨轮结算与下一 Round

1. Round 依据最终持牌、CABO、Kamikaze 和适用的 +10 处罚形成每人**最终 Round Score**。
2. Game 将该已完成 Round 的结果**恰好应用一次**到各玩家累计。
3. 对本局尚未使用重置资格且加分后**恰好 100** 的玩家，累计重置为 50，每人每局最多一次。
4. 用完整加分及适用重置之后的累计检查是否**有人超过 100**；仅等于 100 不结束 Game。
5. 满足 Game End 时，累计最低者获胜；并列时比较最后一个已完成 Round 的得分，再并列则共同获胜。
6. 未满足 Game End 时，以刚完成 Round 的**最终 Round Score** 选下一轮起始玩家；最低分并列时，从上一 Round 起始玩家**本人起**沿顺时针选择第一位并列最低者。
7. Game 自动启动下一 Round，无需房主或玩家确认。可以有不可操作的内部过渡，但不能在 Game End 判定前正式开启新 Round，也不能对玩家暴露相互矛盾的可操作状态。

Round Score 与 Game 累计是不同的事实。Kamikaze、CABO 及额外罚分影响 Round Score；100→50 只影响 Game 累计。Game Aborted 前正式 Completed 的 Round 必须与历史累计保持一致，不得重复或遗漏应用。

## 5. Round

### 5.1 职责

Round 负责本轮 52 张牌、抽牌堆和弃牌堆、每名玩家当前有序牌列、初始发牌与秘密查看、起始玩家与 Turn 调度、CABO Final Turns、抽牌堆耗尽规则，以及本轮最终计分。

每个新 Round 重新洗牌、发牌，并执行初始查看；前一轮的牌面知识不转移为新一轮的查看授权。

### 5.2 初始查看屏障

每名玩家初始获得四张背面牌，并拥有一次查看**最多两张不同初始牌**的机会。它属于 Round 开局阶段，不属于普通 Turn。

所有参与者的初始查看流程必须已终结（主动完成/提前放弃，或超时自动结束），才可创建本轮第一个 Turn。不要求玩家实际上看完、记住两张牌。

初始查看断线可恢复尚未结束的机会，不重新获得额外次数或截止时间。

### 5.3 Turn 调度与轮次结束

Round 决定当前行动者、何时创建下一 Turn、是否仍可呼叫 CABO、谁尚有最终行动机会以及何时结算。任意时刻最多有一个活动 Turn。

- CABO 只能在合法的正常 Turn 开始时呼叫；呼叫者不再行动，其余玩家顺时针最多各获得一次 Final Turn。Final Turns 中不可再次呼叫 CABO。
- 如果抽牌堆耗尽，已开始的合法行动必须完整结束；之后立即结算，不再开启新的 Turn，即使 CABO 的最终行动机会尚有剩余。
- 如果额外惩罚牌抽走最后一张，仍须正常放置惩罚牌，再结束当前 Turn 和 Round。
- Round **Completed** 时，当前 Turn 必须已正常完成，且已产生正式 Round Score。
- Game 强制中止时，尚未完成的 Round 为 **Aborted**，不进行正常结算、不产生本轮得分；此前 Completed 的 Round 仍有效。

### 5.4 轮次计分责任

Round 判定真实手牌总和、CABO 是否成功（允许并列最低）、CABO 失败 +10、项目特殊额外 +10，以及 Kamikaze 优先级。

Kamikaze 必须恰有 `[12,12,13,13]`，其本人本轮 0、其他人各 50，覆盖 CABO 与额外 +10。CABO 成败比较**实际牌值总和**，不比较包含罚分的 Round Score。

完整牌面细则和计分优先级以 `docs/game-rules.md` 为准。

## 6. Turn

### 6.1 身份与职责

Turn 是有独立身份、生命周期的 Entity。同一玩家在同一 Round 中不同次获得的行动机会，是不同 Turn；但不据此断言 Turn 是独立 Aggregate。

Turn 负责本次行动中正在等待的合法选择与执行结果，例如抽牌、弃牌、替换目标、多牌替换后的必要位置选择、技能目标选择、临时查看确认等。

Turn 不自行决定下一行动者、Round 是否结束或跨轮累计。它执行的合法性受所属 Round 当前阶段与服务器权威状态约束。

### 6.2 终结与恢复

- **Completed**：一次行动按规则完整结束，包括合法的多牌替换失败或因超时合法自动兜底完成。
- **Aborted**：所属 Game 被房主强制终止，未完成的当前 Turn 中止，不视为玩家执行了失败操作。
- 断线本身不结束 Turn；如未超时和未终止，玩家重连继续**同一个** Turn。
- Completed / Aborted Turn 不可再次执行行动，不能跨 Round。
- 保留行动者、结束结果及必要摘要，不要求完整 Replay 或事件溯源；历史摘要不能默认向所有玩家公开秘密牌值。

## 7. Card 与 CardSlot

### 7.1 Card

每张具体 Card 在所属 Round 内有稳定内部身份。数值相同的 Card 仍然是不同实体；交换、移位、插入或重排不改变同一 Card 的身份及真实数值。

公开/背面状态按照规则改变；Swap 交换具体 Card，牌各自保持交换前正反面状态，不因换到曾经公开的位置而自动翻面。

**服务器内部 Card ID 不默认暴露给客户端。** 稳定标识可能让客户端持续追踪背面牌，超出合法公开信息。

### 7.2 CardSlot

CardSlot 表达玩家**当前有序牌列中的位置关系**，没有独立领域身份。插入左端、删除或替换会改变其他 Card 的位置编号，而不改变 Card 身份。不能把旧位置编号永久等同于某张 Card。

位置选择只能根据有效的游戏状态解释：若牌列已经改变，不得将过期选择静默作用到后来占据同一位置的另一张 Card。

### 7.3 替换规则的领域含义

- 从弃牌堆取牌必须用于替换；新牌在玩家牌列中保持正面朝上，不能触发能力。
- 从抽牌堆得到的牌可弃掉并放弃能力，或尝试替换；成功入列时为背面朝上。
- 单牌替换无需数值匹配。
- 多牌替换可选择不相邻旧牌；全部同值则成功，新牌占据**所选旧牌**中的一个位置，其余未选旧牌维持相对顺序。
- 多牌不匹配时，被选旧牌保留原位并翻开；通常将新牌插入左/右端；选至少三张失败则额外抽**一张不可查看的背面惩罚牌**，在新牌之后另行选左/右端插入。
- **最后主抽牌 + 至少三张旧牌替换失败**：按 House Rule 旧牌留原位公开，最后主抽牌弃掉，不插新牌、不抽惩罚牌，本轮额外 +10，随后结算；Kamikaze 覆盖额外 +10。
- **最后主抽牌 + 两张替换失败**：新牌仍须入列，无额外惩罚牌和额外 +10，当前行动完成后结算。
- **惩罚牌恰好耗尽牌堆**：惩罚牌正常入列，没有替代 +10，完成当前行动后结算。

不得仅根据结算时牌堆为空，就误用只适用于“最后主抽牌”的 +10 特例。

## 8. Temporary Reveal 与隐藏信息

### 8.1 不建立永久 PlayerKnowledge

服务器保存真实 Card 和当前牌局事实，但 MVP 不记录用于给玩家提供永久提示的观察知识，也不向玩家持续开放过去 Spy、Peek 或初始查看所得的隐藏数字。

Temporary Reveal 是**本次合法步骤**对**特定查看者**、**特定目标 Card** 的限时授权；不预设独立 Entity。

### 8.2 查看流程

- **Initial Reveal**：Round 初始阶段，每人可选择并查看最多两张不同初始牌；可以主动提前结束并放弃剩余机会。
- **Peek**：仅允许在合法能力步骤查看自己的指定背面牌。
- **Spy**：仅允许在合法能力步骤查看其他玩家的指定背面牌；Spy 行动者、目标玩家及目标位置按规则公开，**牌值仅授权给 Spy 行动者**。
- Peek/Spy 目标正式确定后，重连不得重新选择另一个目标。
- 正在查看时可以主动结束；主动结束或到期后，授权立即失效，该步骤按规则完成，Turn 随之完成。
- 当前查看步骤未终结且未超时时允许跨断线恢复**同一次**查看，不能因此增加目标或刷新计时。
- Turn Completed、Round 结束或 Game Aborted 后，不得保留该秘密查看的有效权限。

### 8.3 主动结束的防误触确认

**所有查看时限都是上限，不是最短等待时间。** 玩家可提前结束初始查看或 Peek/Spy，合法 Turn 完成后亦无须等满时限。

- 初始两张牌仍有未使用机会时，点击“结束查看”应显示二次确认，告知将放弃的剩余次数。
- Peek/Spy 已确认目标但结果尚未展示时，主动结束须二次确认，告知之后无法再次查看。
- 两张初始牌均已查看，或 Peek/Spy 结果已经展示时，可以直接结束查看。
- 点击“结束”但尚未确认时，不改变查看步骤；取消提示可继续查看。
- **确认提示不暂停计时**。如果提示停留至截止时间，按超时自动结束；之后的旧确认不得重新启用授权。
- 主动结束与超时结束是同一步骤的互斥终结结果，只能生效一次。
- 二次确认是 UI 防误触要求，不构成独立游戏阶段，不赋予额外查看时间或权限。

### 8.4 服务端可见性原则

隐藏牌的真实数字仅在当前接收者合法有权查看时才发送；不得发送 `{value: 5, visible: false}` 再依赖前端隐藏。普通玩家视图和历史行动摘要不得无条件包含秘密值。

授权到期不能消除玩家已经记住的数字，也不能收回客户端曾经收到的数据；它的含义是服务器**不再重复提供或授权读取**。

## 9. Timeout Policy（项目在线策略）

### 9.1 正式限时

| 范围 | 最大时长 | 起点 |
| --- | ---: | --- |
| 每名玩家初始查看最多两张牌 | **45 秒** | 本轮发牌完成并向该玩家开放初始查看 |
| 每次 Turn（包含本次行动全部步骤） | **90 秒** | Round 正式授予该玩家本次行动机会 |
| Peek / Spy 的单次秘密查看 | **15 秒** | 目标正式确认并向查看者开放结果 |

Peek/Spy 实际截止时间是**单次查看上限**与**Turn 原截止时间**中较早者。Initial Reveal 不属于 Turn，独立计时。

以上均为最大等待时间；玩家完成合法步骤时可立即继续，不需耗尽倒计时。

### 9.2 断线与时间权威

- 服务器掌握截止时间和可操作性；客户端倒计时仅用于展示。
- 断线期间**继续计时**；重连恢复原步骤与剩余时间，不重置截止时间。
- Game 强制 Aborted 时，相应 Turn、Round 和秘密查看权限立即失效，不因未到截止时间而保持有效。
- 即使玩家打开提前结束的二次确认提示，原截止时间仍继续推进。
- 到期自动完成与同时到达的玩家操作不得双重生效。正式被接受的合法行动，不因其后服务器处理越过截止时间而被撤销；精确竞态裁决留待后续并发阶段。

### 9.3 初始查看到期

每人 45 秒覆盖两张牌的选择、展示与确认。超时结束尚未使用的机会；不假定玩家实际看过全部两张。所有人主动完成/放弃或超时后，Round 才能开始首个 Turn。

### 9.4 普通 Turn 超时兜底

原则：服务器根据**当前合法阶段**完成尚未结束的动作，不撤销已正式生效的动作，不读取隐藏牌值替玩家优化策略。

- **未开始选择**：若可合法从抽牌堆抽取，默认抽取一张并弃掉，不发动能力。
- **从抽牌堆取牌、尚可选择处理**：默认弃掉该牌，不发动尚未执行的能力。
- **从弃牌堆取牌**：不能直接弃掉，必须单牌替换；默认替换自己当前牌列**最左侧的一张合法旧牌**。
- **已接受 Replace/Swap 等正式行为**：保持其效果，不再按“尚未行动”兜底；只完成必要的未决选择。
- **客户端尚未提交的多牌选择草稿**：不视为已经正式尝试多牌替换。
- **Peek/Spy/Swap 尚未确认合法目标**：自动放弃未执行的能力；已执行 Swap 不回滚或重复。
- **Peek/Spy 已进入查看**：到查看或 Turn 截止时，自动关闭查看并撤销授权，完成相应 Turn。
- 所有超时默认操作仍需遵守 CABO Final Turns 和最后抽牌的正常结束规则。

### 9.5 多牌替换的未决选择

- **成功**：若尚未确认新牌保留位置，默认选择已选旧牌位置中**最靠左**的一个，不是任意整列最左位置。
- **失败**：需要插入本次新牌、额外惩罚牌时，对**各个尚未确认**的左右选择分别默认**左端**；已经确认的方向保持不变。
- 新牌先放，惩罚牌后放；不得因超时改变已经判定的匹配成功/失败。
- 最后主抽牌触发至少三张失败的 +10 House Rule 时，两张新增牌均不存在，因而**没有插入方向可兜底**。
- 最后主抽牌触发两张失败时，新牌正常入列；未决方向仍默认左端。
- 惩罚牌恰好耗尽牌堆时，按正常失败规则入列后结算，无额外替代 +10。

### 9.6 终结结果唯一

玩家的提前确认、Turn 正常操作、服务器超时兜底与房主强制终止，必须依据有效领域阶段形成**唯一合法结果**，不能重复结束 Turn、重复应用 Round Score、重复改变牌列或重新授权秘密值。

## 10. 跨领域不变量

1. Room 最多四人，Game 进行中不可加入；Game 参与者及座次固定。
2. 房主 Start 需要 2–4 人、非房主全部 Ready；Game 结束返回 Lobby 时重置 Ready。
3. Game Completed 与 Aborted 是不同终局；Aborted 不产生 Winner，历史已完成 Round 得分保留。
4. 每个有效 Completed Round 的结算对 Game 恰好生效一次；Aborted Round 不产生正式分数。
5. Game End 在加分、100→50 重置后判断；判断完成前不得正式启动下一 Round。
6. 下一 Round 起始玩家由上轮最终 Round Score 与已定顺时针并列规则决定。
7. 同一 Round 任意时刻最多一个活动 Turn；一个 Turn 仅属于一个 Round。
8. Completed/Aborted Turn 不能继续行动；断线不直接 Aborted Turn。
9. 初始查看流程全部终结前不能开始首个 Turn。
10. 牌堆耗尽后必须完成当前合法行动，但不再创建新的 Turn。
11. Card 内部身份稳定；CardSlot 是有序位置关系，不具有独立身份。
12. 位置选择不得在牌列变更后错误作用于另一张 Card。
13. Temporary Reveal 只能向当前合法查看者提供具体隐藏值；断线不刷新机会，终结后不再授权。
14. 主动结束/超时结束查看只生效一次；防误触确认不会暂停时间。
15. 超时兜底只能完成合法的未决动作，不利用隐藏值进行策略优化，不改写已生效结果。
16. 玩家操作、超时和强制中止之间，不允许出现双重合法结果或矛盾的可操作状态。

## 11. 明确保留的待决项

- Lobby 中普通成员离开、房主离开或转移的策略。
- 超时后的详细对局提示、长期离线 UX、观战（不在当前 MVP）。
- 截止点的精确裁决、重复命令与并发顺序的实现。
- 位置选择引用失效状态时的具体验证机制。
- 玩家视图、历史公开程度与 WebSocket/HTTP Contract。
- Domain Aggregate / Transaction / Persistence 的最终技术边界。
- 后续是否支持 Replay、观战和完整操作审计。
